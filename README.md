# 📦 Sistema de Estoque - Bike Store

Sistema web de gerenciamento de estoque desenvolvido com:

- Python Flask
- SQLite
- HTML
- CSS
- JavaScript

---

# 🚀 Funcionalidades

✅ Login administrativo  
✅ Cadastro de produtos  
✅ Controle de estoque  
✅ Exclusão de produtos  
✅ Histórico de movimentações  
✅ API REST Flask  
✅ Interface responsiva  
✅ Proteção de rotas
